# db_rental_studio
Aplikasi Rental Studio Musik berbasis PHP-MySQL ini berfungsi mengatur jadwal sewa studio agar jam latihan antarband tidak bentrok. Memiliki 3 tabel berelasi (Ruangan, Pelanggan, Booking), web ini dilengkapi hitung biaya otomatis (harga x durasi), penanda status DP/Lunas, serta Rekap Bulanan untuk memantau omzet transaksi secara real-time.
